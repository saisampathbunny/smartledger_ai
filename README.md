# SmartLedger AI

A fraud detection system for bank transactions. Transactions are scored against rule-based fraud checks, and flagged ones get a plain-English explanation generated by Google Gemini AI.

## What it does

- Stores bank transactions in a MySQL database
- Scores every transaction against multiple fraud signals (not just amount)
- Uses Google Gemini AI to explain, in plain English, why a transaction was flagged
- Displays everything on a simple dashboard, highlighting suspicious transactions in red

## Tech Stack

- **Frontend:** HTML, JavaScript (no framework)
- **Backend:** Java, Spring Boot (REST API)
- **Database:** MySQL (Spring Data JPA + Hibernate)
- **AI:** Google Gemini API for fraud explanations

## How it works

1. A transaction is submitted through the dashboard.
2. The backend runs it through `FraudDetectionService`, which scores it out of 100 based on:
   - Large amount (> ₹50,000)
   - Self-transfer (sender = receiver)
   - Odd-hour transaction (12 AM–5 AM)
   - Round-number amount
3. A score of 50+ marks the transaction `SUSPICIOUS`; below that, `SAFE`.
4. `GeminiService` sends the transaction details and score to Gemini, which returns a one-sentence explanation.
5. The transaction, status, and explanation are saved to MySQL and shown on the dashboard.
